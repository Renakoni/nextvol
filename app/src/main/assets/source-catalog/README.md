# 书源目录

`catalog.json` 保存展示名称、分类、展示域名及对应定义在批次中的位置；`key` 必须与批次中完整的 `bookSourceUrl` 一致。分类只按该身份匹配，不从名称、原分组或域名推断。

添加页按“导入 / 分类”排列，默认打开导入。六个分类补充可读书源，付费平台按内容归入相应分类，条目中注明部分作品可能需要付费；用户仍按原流程跨分类勾选、预览并确认权限。分类不改变源身份或已保存的账号、授权和其他偏好。`available` 控制是否提供添加，撤下项仍保留身份与分类，已有安装不被删除。

目录保留92个已知身份，提供74项添加：主流18、女频15、二次元9、文学典籍15、综合9、成人8。番茄、七猫、爱丽丝、hlib及原有综合站恢复可选。曾单列的“官方站点”分类内容混杂，已撤销，晋江、起点等平台回到原分类；旧安装中保存的该分类名读取为空，启动时按目录重新归类。涩涩俱乐部站点已失效，移出目录。分类调整只移动完整定义并更新索引，不改写原规则，也不删除已安装来源。

成人分类收录 [PixivSource](https://github.com/DowneyRem/PixivSource) v284 主小说源，完整身份为 `https://www.pixiv.net/novel`；保留来源身份与作者说明，不收录备用源和漫画源。内置版本修正了游客登录误判：UID 只从当前 Cookie 存储中的具名 PHPSESSID 提取，不依赖短期缓存；主动登录由账号接口确认，凭证变化后刷新 CSRF，收藏等操作按当前会话重建请求头。公开发现可供游客读取，受限响应不会自动清除 Cookie。已有精确版本通过 `replaces` 更新，用户修改过的规则保留。添加后仍须按原流程确认权限，内容可见性由站点账号权限决定；目录不包含个人账号或会话数据。

Pixiv 的“阅读与搜索”保留整合系列、搜索作者、繁简通搜、显示描述和显示插图；移除更多简介、章节编号、原始链接、恢复《》、自动收藏/取消、隐藏收藏/追更的入口及专属实现，手动收藏、追更和屏蔽不变。简介保留原文，更新时间直接取小说或系列的 `updateDate` 交给详情页，不再通过目录分页补日期；字数沿用已有 `textCount` / `publishedTotalCharacterCount`，缺失时仍由详情页隐藏。

Pixiv 的“发现页设置”统一管理首页栏目与扩展分类，面板直接从 R18 推荐开始；新装和恢复默认只开启原有八组。升级仅将明确匹配旧默认的组合迁移为八组，保留自定义选择。我的收藏与私密收藏沿用当前账号的公开、私密收藏接口，默认关闭，未登录时灰显并提示登录；其他分类不会绕过收藏开关或重新加入已关闭的首页栏目。已移除“书源相关入口”及专属链接处理，不影响主面板的功能手册和阅读器接管的更新按钮。首页模块的 `optional: true` 允许引用分类因设置关闭或未登录而缺席；重复匹配、空目标及非可选模块仍按原有规则校验。

可添加不等于在线实读已经通过。不得因为暂未核验、网络失败或本应用尚未兼容而批量隐藏条目；核验沿原规则的发现、详情、目录和正文链路，与阅读实跑及源码对照。候选须抽查开篇、中段和末章，公告、验证码、订阅提示、待更新占位和拼接文字不算通过。网络失败不等于网站过期，抽样通过也不保证站点全部作品或未来可用性。

明确撤下轻小说机翻、连城读书；无发现规则的9项不提供一键添加。ESJ已跳转域名停放页，鲸云发现API证书失效，疯情有既有安全阻断；八一中文出现占位及拼接内容，全本小说和趣书网样本在原站缺章，暂不提供添加。掌阅原规则在本应用与阅读中均出现首章串入大量内容、中末章返回应用下载提示，经同书状态与缓存核对后撤下推荐。经典书库保留并注明部分正文使用图片文字，不把本应用的图片处理限制归为站点失效。

发现首页与分类列表沿各自语义展示；只有分类的源不伪造榜单或推荐首页，仍可在分类页使用。已维护的轻小说百科、全本同人、国学典籍及补充站定义保持原样；本轮兼容修复在解释器和执行链完成，不为通过测试再改写书源。国学典籍保留原站句读和段落，不自动补标点或按字数断句。

官方站保留公开阅读与原有登录能力，付费权益由站点决定，本轮未验证已订阅账号的付费全文。纵横、磨铁、花溪的当前规则未提供登录入口，条目中明确标注；起点榜单限网页前20，免费目录与正文无需强制登录；米国度搜索需登录，刺猬猫可能需要网页验证码。

`replaces` 仅列已发布原版定义的内容摘要，启动时只修复这些精确版本；保留账号、授权、来源和偏好，保护用户修改、待应用自定义导入和显式回退。目录分类以当前已知身份更新，其余偏好不变。新增访问域名继续经过现有权限流程，不扩大旧安装的授权。

维护批次时保留规则作者说明与来源身份，不提交个人Cookie、账号标识或token。规则、目录、请求及浏览器的实站材料放在被忽略的本地调研目录；仓库只保留生产代码和必要回归。修改批次后同步索引、精确旧摘要并运行 `SourceCatalogTest` 与相关界面回归。
