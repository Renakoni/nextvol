# 书源目录

`catalog.json` 保存展示名称、分类、展示域名和对应 JSON 中的位置。`key` 必须与定义的完整 `bookSourceUrl` 一致，`index` 指向同分类文件内的定义；分类不从名称、旧分组或域名猜测。

当前目录共 71 个维护源，全部提供添加：主流平台 18、女频 15、二次元 10、文学典籍 12、综合 8、成人 8。确认失效、正文错乱且无法修复的条目直接删除，不保留不可添加的身份，不提供旧定义摘要迁移。

## 发现与分类

每个内置源都提供能展示书籍的发现首页，通过 `homepageModules` 或已有的网站导航规则生成。官网有榜单、推荐或新书时使用对应书单；只有分类的站点使用“分类 · 分类名”书单作为首页，不把它命名为推荐榜。分类页只放真实分类、主题标签及必要筛选，排行、登录、充值和说明入口不充当分类。

维护源的语义由规则显式声明。通用导入源仍按导入规则运行，本轮不增加按“月榜”“周榜”等关键词自动重写发现的功能。用户添加来源时继续预览定义并确认访问权限。

## 维护规则

- 番茄：官网负责搜索、分类、详情和目录；正文依赖第三方公共 HTTP 接口。该服务是阅读可用性的外部依赖。
- 哔哩轻小说：依据官网独立编写精简规则，使用网站浏览器还原段落，只读取可见正文和插图，合并同一章节的分页。发现包含最近更新、周点击和新书，分类使用官网真实地区与主题。未接入评论、圈子、站点书架和扩展控制面板。
- UAA：使用当前官网的书单、详情、目录与正文页面。会员和付费章节按网站权限访问。
- 九九藏书、和图书：由网站页面完成正文还原后提取可见段落。经典书库保留图文内容，汉典等站点沿用应用的证书确认流程。
- 飞卢：区分免费与 VIP 目录项，登录和订阅提示不作为正文。塔读：提取章节接口中的正文，游客后续章节按官网显示预览。
- 刺猬猫：使用与解析规则一致的桌面页面，避免手机端跳转移动站后出现详情和目录解析错误；图片验证码沿用网站验证流程。
- PO18：首页、榜单和标签使用当前官网链接；首次访问需在网页确认年龄，阅读需要登录。公开检索入口未配置。
- 官方平台保留公开章节；登录、付费或广告解锁范围由站点决定。预览和登录提示不得记录为付费全文验证通过。

网站验证使用应用现有的网页流程；网页广告弹窗与通用广告拦截另行处理。代理与直连任一能够访问即保留，网络失败须结合网站实际状态判断。

Pixiv 小说保留主小说源身份与作者说明。阅读、搜索和发现设置由现有原生面板管理，收藏、追更等操作遵循当前账号权限；不加入备用源、漫画源和个人会话数据。

## 验证

维护时核对发现书卡、真实分类、详情、目录、首段和后段正文，并在 Android 应用内执行生产引擎验证。分页应产生新增书籍或同章内容；验证码、登录提示、拼接文字和占位内容不算正文通过。图片需验证实际解码。

目录和索引由 `SourceCatalogTest` 校验，正文变更运行对应书源回归。哔哩的浏览器提取另有 Android 回归，检查隐藏干扰段落、尚未加载的插图、评论排除和同章分页边界。只运行相关测试，不运行本地全量测试。

保留规则作者说明与来源身份。账号、Cookie、Token、调研样本、截图和请求日志不进入仓库。
