# NextVol 0.2.3

这一版重新整理了从找书、继续阅读到听书的常用界面。首页可以横滑切换最近读过的书，阅读时可以直接打开目录、书签和排版面板。思源宋体和霞鹜文楷改为单独下载，想用哪款就下载哪款。

## 版本特性

- **从首页接着读。** 「正在阅读」把最近阅读放在横向轮播里，纵向滑动查看阅读记录。书架的排序、多选和批量操作集中在各自的入口，书籍详情页的阅读按钮在长目录中也能找到。
- **主题和排版可以当场预览。** 「设置 → 主题与纸张」支持浅色、深色和跟随系统，只展示当前外观对应的配色。调字号、字重、行距和段距时，可用同一把刻度尺查看文字效果。
- **字体按需下载。** 在「主题与纸张 → 文本字体」点思源宋体或霞鹜文楷即可单独下载。下载完成后可以离线使用，也可以继续用系统字体或导入自己的字体文件。
- **本地听书支持 GPT-SoVITS V2 音色。** 可导入音色、指定参考音频的语种，并处理中文正文里的混读。播放器会把已经准备好的下一段按顺序接上，合成按当前可播放的余量安排。
- **发现、分类与搜索。** 分类目录会按可用宽度排列；全局搜索、单书源搜索和结果筛选的入口更明确。底部导航支持点按和拖动切换。

## Changelog

- 阅读统计重新排布日历热力图和阅读记录。阅读器的顶部、底部工具栏以及听书浮窗也更新了布局。
- 设置中心重新分组，书源列表增加搜索。听书设置按播放、音源与语音库整理，语音运行库支持双源下载、进度显示和取消。
- 改善本地 EPUB 导入兼容性，移除固定文件大小限制，统一书籍简介的显示并保留 EPUB 简介中的段落。
- 恢复应用内语言切换，移除阅读器的手动汉字变体设置。
