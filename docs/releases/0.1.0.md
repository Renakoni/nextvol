# NextVol 0.1.0

NextVol 的首个公开版本。这个版本先确定发布渠道和安装包签名，为后续迭代及应用内更新提供基础。目前仍在开发中，欢迎试用和反馈。

## Changelog

### 首发功能

- **书架与阅读记录**：创建和管理书架，收藏书籍，保存阅读进度与书签，查看阅读统计。
- **书源与找书**：使用内置书源浏览、发现和搜索书籍，也可导入 JSON 规则书源。
- **阅读器**：支持滚动和翻页模式，可调整字体、排版、主题与背景。
- **离线阅读**：下载和缓存章节，管理下载任务及已缓存内容。
- **本地书籍与数据管理**：导入 EPUB / TXT，导出 EPUB，备份与恢复阅读数据。
- **听书**：支持系统朗读引擎和 HTTP 音源，可调节语速、设置睡眠定时。

### 近期修复与调整

- 优化长章节的排版与加载，修复阅读页和主页的部分闪空问题。
- 修复批量标记已读后阅读统计不准确的问题。
- 调整阅读设置页面的顶部布局，对齐字体导入入口。

## 下载

下载附件 **`NextVol-0.1.0-release.apk`** 后打开安装，需要 **Android 7.0 或更新版本**。这是通用安装包，无需选择 CPU 架构。

`SHA256SUMS` 提供安装包的 SHA-256 校验值。GitHub 自动生成的 Source code 压缩包是源码，不是安装包。

## 使用说明

- 本次先建立 Release，应用内更新源的迁移随后单独完成。当前请从本发布页手动下载 NextVol，不将现有应用内更新提示视为 NextVol 的更新。
- Debug / Snapshot 与正式版分开安装。已有同包名构建若使用其他签名，无法直接覆盖安装；迁移前请先备份需要保留的数据。
