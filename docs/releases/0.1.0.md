# NextVol 0.1.0

NextVol 的首个发布基线，用于建立版本、签名、下载附件和后续应用内更新所需的 GitHub Release。此版本仍处于早期开发阶段，不代表全部功能已经稳定。

## 下载与安装

下载 **`NextVol-0.1.0-release.apk`**，打开后按 Android 的提示安装。需要 **Android 7.0（API 24）或更新版本**；这是包含所支持 CPU 架构的通用安装包。

| 项目 | 值 |
| --- | --- |
| 仓库 | `Renakoni/nextvol` |
| 标签 | `v0.1.0` |
| 版本名称 | `0.1.0` |
| Android 版本码 | `10300009` |
| 应用 ID | `indi.renakoni.nextvol` |

版本名称从 `0.1.0` 开始；内部版本码延续已有构建并递增。后续正式版持续使用同一签名和更高的版本码。

## 附件与校验

- `NextVol-0.1.0-release.apk`：已签名的 Android 安装包。
- `NextVol-0.1.0-release-notes.md`：本发布说明。
- `SHA256SUMS`：以上两个文件的 SHA-256 校验值。

发布签名证书的 SHA-256 指纹：

```text
87:B6:1D:CF:3E:EC:CA:2B:93:AC:B8:AA:E0:35:CE:01:62:60:50:8E:09:E2:05:26:69:12:70:35:23:EF:AC:FC
```

GitHub 自动提供的源码 ZIP / TAR.GZ 不是安装包，不包含在 `SHA256SUMS` 中。

## 更新与兼容边界

本版本作为 GitHub 的最新正式 Release 提供版本信息和 APK，供后续 NextVol 更新接入使用。**应用内更新源的迁移另行完成**；当前请通过本发布页手动下载 NextVol，不将现有应用内更新提示视为 NextVol 的更新。

Debug、Snapshot 和上游 LightNovelReader 使用不同安装标识，不能作为本正式版的原地升级来源。已有同包名构建若使用其他签名，也不能直接覆盖安装；迁移前请导出需要保留的数据。首次发布没有更早的 NextVol 正式签名版本可用于跨版本升级验收。

源码与许可证随发布标签提供；发布流程见[发布指南](https://github.com/Renakoni/nextvol/blob/v0.1.0/docs/releasing.md)。
