# NextVol 0.1.0

NextVol 的第一个公开版本，也是后续版本迭代和正式安装包升级的起点。这个版本汇集了 300 多个 PR 的开发成果：从书源、找书和阅读，到离线下载、听书、本地书籍与数据备份，建立日常使用所需的基础。

## 版本特性

- **找书与书源管理**：内置书源目录、JSON 规则书源导入、多书源搜索，以及按书源分类浏览和管理。
- **可定制的阅读器**：滚动、翻页与双页布局，离线字体、纸张主题、排版预览，配合书签和阅读进度恢复。
- **离线与本地阅读**：按卷或章节下载，导入 EPUB / TXT，导出 EPUB，并管理缓存和存储空间。
- **听书**：系统朗读与在线音源、后台播放、句段高亮跟随、悬浮控制和睡眠定时。
- **书库与阅读数据**：多书架、阅读记录和统计、Bangumi 卷进度同步，以及 `.nvbackup` 备份恢复。

### 书源、发现与搜索

- 从分类目录选择书源，也可导入单条或批量 JSON 规则；导入前预览内容并确认访问网站。
- 按书源管理启用状态、账户、网站授权、变量和网络设置；一个书源可以加入多个分类。
- 完整 JSON 编辑器支持查找替换、格式化、语法校验和错误位置跳转。
- 发现与分类页面保留各自的来源和浏览位置；书源较多时可筛选分类、分页选择。
- 搜索支持全部书源、单个书源或分组，逐步展示结果，可暂停、继续、加载更多及重试失败来源。
- Wenku8 搜索结合原站、本地书目和 Bangumi 公开资料识别别名与常见缩写，也支持书籍 ID 或链接定位。
- 支持需要账户或网页验证的书源；登录、验证与规则配置按各书源实际能力提供。第三方站点的可用性仍取决于其服务和规则。

### 阅读与外观

- 支持连续滚动和分页阅读；分页可选择自动、单页或双页，双页受窗口大小、字号与内容兼容性限制。
- 调整字体、字号、字重、行距、段距和页边距，并在设置中查看页面预览。
- 内置思源宋体、霞鹜文楷，可离线使用，也可导入本地字体。
- 提供纸张样式、主题配色和背景设置，支持减少动画；音量键可用于翻页或滚动。
- 目录支持章节搜索、当前章定位、分卷折叠和长目录分页；可以选择单章或多章标记已读、未读。
- 书签保存正文位置，可查看、跳转、删除并随备份恢复；切换模式、改变字体或窗口后按正文位置重新定位。

### 离线下载与存储

- 下载前按卷、按章勾选范围，任务保存所选章节，并区分“所选章节已完成”和“整书已离线”。
- 下载任务支持进度查看、取消、失败重试和中断后恢复；正文与图片分别保留可复用的完成结果。
- 已下载内容可离线阅读；需要网站验证的任务可在验证后继续，更新下载尽量复用有效缓存。
- 存储管理展示占用情况，并区分阅读缓存、下载内容和本地书籍的清理范围。

### 本地书籍与 EPUB 导出

- 从应用内选择文件，或通过其他应用的打开、分享入口导入 EPUB / TXT，统一收进“本地书籍”书架。
- TXT 可调整编码和章节规则，确认前预览目录与正文；EPUB 支持目录、分卷内容、封面和本地图片。
- 导入后保存独立副本，移动外部原文件不影响当前设备上的阅读。
- 在线书籍可按卷准备 EPUB，选择文字或带图内容；支持后台导出、完成通知及系统分享。

### 听书

- 使用已安装的系统 TTS 引擎，或选择内置、自行导入的 HTTP 在线音源；提供统一音源选择、试听及语速设置。
- 支持后台播放、媒体通知控制和自动衔接章节；听书进度与普通阅读进度分别保存。
- 正文显示当前朗读句段并自动跟随；手动浏览可暂时脱离跟随，点击悬浮封面回到朗读位置。
- 应用内悬浮播放器可拖动、吸边、暂停或停止，无需系统悬浮窗权限。
- 可设置 15 / 30 / 45 / 60 分钟定时停止。在线服务需要网络，部分音源还需自行配置账户凭据。

### 书库、统计与数据备份

- 创建和管理多个书架，收藏书籍，查看最近阅读、章节进度、阅读时长和读完统计。
- Wenku8 阅读记录可匹配 Bangumi 小说条目并同步已完成册数；支持核对匹配、手动修正和查看同步结果。
- `.nvbackup` 可按选项备份书架、阅读数据、设置、书签及章节缓存，也可分享书架。
- 恢复前检查备份格式与版本；覆盖恢复中的数据写入失败会回滚，保留原有书库与离线文件。
- 备份不包含原始 EPUB / TXT 文件；换设备前需另存原文件，恢复后重新关联。旧 `.lnr` 仅保留受限读取能力。

- 整理后台导出、完成通知与分享文件的生命周期，保证分享接收方可通过授权读取生成文件。

[SHA256SUMS](https://github.com/Renakoni/nextvol/releases/download/v0.1.0/SHA256SUMS) 提供安装包的 SHA-256 校验值。GitHub 自动生成的 Source code 压缩包用于获取源码。

- 本次先建立正式发布基线，应用内更新源迁移随后完成。当前请从本发布页手动下载；现有应用内更新提示尚不代表 NextVol 的新版本。
- Debug / Snapshot 与正式版分开安装。已有同包名构建若使用其他签名，无法直接覆盖安装；迁移前请先备份需要保留的数据，并单独保存本地 EPUB / TXT 原文件。
