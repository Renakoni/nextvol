# NextVol 0.1.0

这是 NextVol 的首个占位发布，用于建立版本标签、发布说明和后续发布流程。它标记为 **Pre-release（预发布）**，不代表功能已经稳定，也不提供可安装 APK。

| --- | --- |

版本名称从 `0.1.0` 开始；内部版本码延续已有构建并递增，后续发布不得降低。

## 附件

- `NextVol-0.1.0-release-notes.md`：本发布说明。
- `SHA256SUMS`：上述附件的 SHA-256 校验值。
- GitHub 自动提供标签对应的源代码 ZIP 和 TAR.GZ；它们不是 Android 安装包，也不包含在 `SHA256SUMS` 中。

本次没有 APK、AAB 或可供安装的更新文件。

## 应用内更新

本发布不进入 GitHub 的 latest 正式发布通道。后续正式发布将提供一个签名的通用 APK；更新接入工作完成后，应用才能通过 NextVol 的正式 Release 检查和下载更新。

`0.1.0` 只建立发布基础，不表示应用内检查、下载或覆盖安装已经完成真实验收。已有开发包和上游 LightNovelReader 不能因此自动迁移为 NextVol 正式版。

发布格式及后续操作见[发布指南](https://github.com/Renakoni/nextvol/blob/v0.1.0/docs/releasing.md)。
