# NextVol 0.2.2

这一版把厂商语音和 GPT-SoVITS 从安装包里拆了出来。只看书，装一个 APK 就够了。要用离线音色，可以到听书设置里下载对应的运行库。阅读器也改了几处常用操作，包括勾选已读章节、切章和按书源分组搜索。

## 版本特性

- **听书运行库按需下载。** 升级后要继续用搜狗、微软、讯飞等已有离线音色，在「听书设置 → 语音运行库」下载「厂商语音运行库」即可。下载完成就能试听，已有音色可以接着用。
- **普通话本地合成。** 接入 GPT-SoVITS V2 Pro 和 V2 Pro Plus 后端，支持用本地模型、参考录音和台词生成语音与整章 WAV。声码器默认使用 WebGPU，在通过探测的高通设备上，长句可使用 NPU。本版设置里提供运行库下载，模型目录与后端调用方式见[接入说明](https://github.com/Renakoni/nextvol/blob/v0.2.2/native/matcha/GPT-SoVITS.md)。
- **朗读优先保留整句。** 小数、英文单词、连续句末标点和右引号会随原句朗读。较长的句子优先在停顿处拆分，普通在线音源直接使用分好的片段。
- **书源分组可以直接用于搜索。** Wenku8 和 Z-Library 现在都在「已添加书源」里管理。一个书源可以放入多个组，在搜索页选组即可限定范围。
- **目录支持跳选已读章节。** 「标记已读」和「标记未读」都可以逐章勾选或全选，适合补记跳着读过的章节。阅读器默认字号调整为 22sp，已有自定义字号继续生效。

## Changelog

- 阅读时复用已预加载的章节和插图。离线下载遇到已缓存的有效原图时直接取用，返回列表时沿用内存里的封面。
- 网站验证完成后，等待中的正文与下载任务可以接着走。验证页增加刷新按钮，Wenku8 接入同一套恢复流程。
- 导入语音包的按钮移到预览页顶栏，引擎配置导入失败时会显示原因。在线音源编辑后保留排序，内置音色支持批量删除。
- 修复微软离线音色 ZIP 首次导入失败，以及讯飞两代离线库的名称冲突。厂商运行库下载遇到网络停滞时可以取消后重试。
- 修复排版正则在编辑时丢失反斜杠、替换时重复处理文字的问题。桌面图标更换为书页形的 N。

### 离线听书与安装包

- 正式版和 Snapshot 统一提供 ARM64 APK。原生调试符号单独保存，厂商 SDK、GPT-SoVITS 的词典、声码器图和 GPU／NPU 运行库随各自的组件分发。系统朗读可直接使用。
- GPT-SoVITS 后端支持 Android 10 及以上的 ARM64 设备。章节合成复用同一音色会话，按朗读计划处理分段和停顿，输出 32 kHz 单声道 WAV。
- 厂商包 v5 修正讯飞经典版与新版同时加载时的库名冲突。微软音色导入时用相对符号链接补齐 SDK 所需的文件名，模型只存一份。

### 朗读、试听与音源管理

### 阅读、插图与书籍列表

- 目录工具栏将章节数放在标题旁。更新目录后，已缓存章节按新目录导航，切章时接续窗口内正在预加载的任务。修复软换行在分页边界的高度偏差。
- 按当前阅读窗口准备插图并复用尺寸，同一原图的并发请求可以共享。命中图片缓存时省去书源准备，下载插图优先复用本地原图。
- 首页「正在阅读」等首次查询完成再显示空状态，返回列表时减少封面闪回占位图的情况。修复部分书籍简介露出 HTML 标签、发现与分类选中不同书源、已有书单刷新时指示器过早消失的问题。
- 阅读页的书源操作移至设置里的书源管理。排版规则按实际命中位置替换，捕获组里的文字和编辑时输入的转义字符可以原样保留。

### 书源、验证与启动

- 书源按实际提供的搜索、目录和正文能力保存与运行。只有目录的书源也能展示章节。聚合搜索沿用管理分组，组内只搜索已启用且支持搜索的书源。
- 脚本验证和人工验证共用请求恢复流程。多个任务等同一次验证时可以一起恢复，下载直接使用验证后取得的正文。普通 HTTP 请求共用总超时。
- 批量恢复书源时一次更新注册列表，运行环境在用到时准备。Bangumi 同步与自动更新工作移到首帧之后。
