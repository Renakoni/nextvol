# NextVol 0.1.1

这次更新主要改善书源的发现、登录和阅读体验：新增哔哩轻小说，修复多家站点的目录、正文与插图解析，补齐书源面板的长按操作，并整理账户设置的布局。

## 版本特性

- **哔哩轻小说**：支持首页推荐、分类浏览、目录、正文和插图，同一章节的多页内容会合并阅读。
- **书源面板长按**：书源定义的长按动作现在可以正常触发，例如 Pixiv 的「取消收藏」可通过长按作用于整个系列。
- **更集中的账户设置**：账户分区移到基础设置之后，登录状态与主要操作并排展示，窄屏和大字体下操作可以换行。

## Changelog

- **内置书源**：整理为 71 个可添加条目，补充首页书单，修复站点改版、手机跳转及分页带来的阅读问题。
- **登录兼容**：修复部分导入书源无法打开登录页的问题，标准登录表单中的选择、切换和默认值等控件可在普通导入模式下使用。
- **进度与存储**：统一阅读和手动已读的整书进度计算；书籍删除失败或取消后，页面能恢复操作。
- **更新下载**：修复重复下载互相干扰、下载失败后继续处理文件，以及取消后仍提示完成或请求安装的问题。

### 内置书源、发现与阅读

- 新增哔哩轻小说，支持首页、分类、详情、目录、正文、插图及同章分页。
- 为维护中的书源补充榜单、推荐、新书或分类书单，首页与分类各有入口；移除失效或已被替代的内置定义。
- 修复番茄的目录与正文地址，减少旧接口失效对阅读的影响；修复刺猬猫手机跳转后无法匹配正文的问题。
- 修正飞卢的目录与付费章节标记、塔读的正文提取，以及咪咕、17K、镜文学、书旗等站点的规则与分页。
- 修复 POPO 的搜索、发现和插图处理，完善部分文学书源的正文还原与图文阅读，避免把登录表单、导航页或购买提示当作章节正文。
- 完善部分书源的网站登录入口和验证页面识别，网站要求的人工验证继续在应用内网页中完成。

相关 PR：[内置书源与哔哩轻小说 #677](https://github.com/Renakoni/nextvol/pull/677)。

### 登录、长按与账户界面

- 修复部分导入书源点击登录后报错、无法打开网站登录页的问题。
- 标准静态登录表单的选择、切换、默认值和动态标签不再受扩展导入模式限制。
- 登录、配置和阅读中的书源面板支持按钮及带动作的选择／切换控件长按。一次长按只触发一次动作，不同时触发单击，也不自行改变当前选项；忙碌或禁用时不能操作。
- 账户分区前移，状态与主要操作并排显示，退出操作保留并降低视觉权重；登录、重新登录、重试和网站验证入口保持可用。
- 改善窄屏、大字体和长账户名的布局；账户名缩短显示时，读屏仍可读取完整名称。

相关 PR：[登录兼容 #722](https://github.com/Renakoni/nextvol/pull/722)、[面板长按 #736](https://github.com/Renakoni/nextvol/pull/736)、[账户布局 #742](https://github.com/Renakoni/nextvol/pull/742)。

### 阅读进度与书籍管理

- 阅读和手动标记已读使用一致的整书进度计算，已经不在当前目录中的旧章节记录不再影响完成度。
- 手动标记已读时忽略过期目录结果，目录暂不可用时保留已有总进度，减少错误覆盖。
- 存储统计与孤立内容清理使用一致的章节归属，已下载的旧章节仍按下载记录保留。
- 删除失败或被取消后释放页面的忙碌状态，根据实际剩余内容恢复列表和选择，并在普通失败时显示提示，方便重试。

相关 PR：[整书进度 #691](https://github.com/Renakoni/nextvol/pull/691)、[章节归属 #692](https://github.com/Renakoni/nextvol/pull/692)、[删除失败恢复 #710](https://github.com/Renakoni/nextvol/pull/710)。

### 更新下载与其他维护

- 更新下载遇到服务器错误时停止后续文件处理，保留原始失败原因，避免被空文件或解压错误提示覆盖。
- 重复点击下载不会再启动相互干扰的任务；取消后不继续发送完成通知或请求安装，失败后仍可重试。
- 整理备份、EPUB 图片准备、存储查询与清理、日志报告和设置菜单的内部职责，保持现有使用方式。
- 调整自动检查的任务范围与构建缓存，修正阅读界面回归检查的等待条件；这些维护不改变应用功能。

相关 PR：[下载失败处理 #707](https://github.com/Renakoni/nextvol/pull/707)、[重复下载与取消 #709](https://github.com/Renakoni/nextvol/pull/709)。

## 下载与升级

下载 **[NextVol-0.1.1-release.apk](https://github.com/Renakoni/nextvol/releases/download/v0.1.1/NextVol-0.1.1-release.apk)**，支持 **Android 7.0 及以上**，无需选择 CPU 架构。

已安装 0.1.0 正式版的用户可直接覆盖安装，无需卸载或清空数据。当前请从本发布页手动下载安装包；Debug、Snapshot 和上游 LightNovelReader 与正式版分别安装。

本次内置书源规则更新包含在添加书源的目录中，升级应用不会自动替换已经添加的规则。使用已有书源时，其内容仍以保存的规则为准。

网站要求的登录、订阅和人工验证仍需完成。部分站点可能受地区、网络或网站风控影响；番茄正文依赖第三方公共服务，其可用性可能变化。
