# NextVol 0.1.1

这次更新主要改善书源的发现、登录和阅读体验。新增哔哩轻小说，修复多家站点的目录、正文与插图解析，并为书源面板补上长按操作。账户设置也重新整理，登录状态和操作放在一起，更容易找到。

## 内置书源与阅读

- **新增哔哩轻小说**，支持首页推荐、分类浏览、目录、正文及插图，同一章节的多页内容会合并阅读。
- **整理内置书源目录**，保留 71 个可添加条目，为维护中的书源补充榜单、推荐、新书或分类书单。首页与分类各有入口，减少榜单和分类混在一起的情况。
- **修复多家站点的阅读规则**，包括番茄的目录与正文地址、刺猬猫的移动站跳转、飞卢的目录与付费章节标记，以及塔读等站点的正文提取。
- **改善图文与分页内容**，修复 POPO 的搜索、发现和插图处理，完善部分文学书源的正文还原与图文阅读，避免将登录表单、导航页或购买提示当作章节正文。

网站要求的登录、订阅和人工验证仍需完成。部分站点可能受地区、网络或网站风控影响；番茄正文依赖第三方公共服务，其可用性可能变化。

## 登录与书源面板

- 修复部分导入书源点击登录后报错、无法打开网站登录页的问题。
- 普通导入模式也能使用标准登录表单中的选择、切换和默认值等控件，减少打开表单时的规则错误。
- 登录、配置和阅读中的书源面板支持按钮长按。书源定义了长按动作时，现在可以正常触发，例如 Pixiv 的「取消收藏」可通过长按作用于整个系列。长按不会同时触发单击，也不会自行改变当前选项。
- 账户分区移到基础设置之后，登录状态与主要操作并排展示，重新登录和退出的主次更清楚。窄屏或大字体下操作可以换行，长账户名缩短显示时，读屏仍可读取完整名称。

## 其他修复

- 书籍删除失败或被取消后，页面会结束忙碌状态，并根据实际剩余内容恢复列表和选择，方便继续操作。
- 修复重复点击更新下载时任务互相干扰的问题；下载失败会保留原始原因，取消后不再继续弹出完成通知或请求安装。
- 阅读和手动标记已读使用一致的整书进度计算，已经不在当前目录中的旧章节记录不再影响完成度。

## 下载与升级

下载 **[NextVol-0.1.1-release.apk](https://github.com/Renakoni/nextvol/releases/download/v0.1.1/NextVol-0.1.1-release.apk)**，支持 **Android 7.0 及以上**，无需选择 CPU 架构。

已安装 0.1.0 正式版的用户可直接覆盖安装，无需卸载或清空数据。当前请从本发布页手动下载安装包；Debug、Snapshot 和上游 LightNovelReader 与正式版分别安装。

本次内置书源规则更新包含在添加书源的目录中，升级应用不会自动替换已经添加的规则。使用已有书源时，其内容仍以保存的规则为准。
